Activer la lecture d’écran

Android 13+ bloque la lecture d’écran pour les apps installées hors Play Store. Aucune app ne peut débloquer ça toute seule — c’est une sécurité système. Tu dois l’autoriser une seule fois dans les réglages (sans câble USB).

Important : le menu « Autoriser les paramètres restreints » est souvent caché tant que tu n’as pas déclenché le message « Paramètre restreint » en touchant CourseOK dans Accessibilité.

Samsung (Galaxy / One UI)

  1. (Si présent) Réglages → Sécurité et confidentialité → Bloqueur automatique → désactive-le, sinon le sideload reste bloqué.
  2. Réglages → Accessibilité → Applications installées → touche CourseOK lecture d’écran (même grisé).
  3. Valide le message « Paramètre restreint » (OK).
  4. Réglages → Applications → CourseOK (ou appui long sur l’icône CourseOK → Infos).
  5. Touche ⋮ en haut à droite ou fais défiler la page → Autoriser les paramètres restreints → confirme avec empreinte / code.
  6. Retourne dans Accessibilité et active CourseOK.

Xiaomi / Redmi / POCO (MIUI / HyperOS)

Le dialogue « Paramètre restreint — actuellement indisponible » (bouton OK seul) est normal sur Xiaomi. Ce n’est pas la fin : il faut ensuite autoriser via Infos de l’app (menu ⋮).
  1. Réglages → Accessibilité → Applications téléchargées → touche CourseOK (même grisé).
  2. Valide « Paramètre restreint » → OK.
  3. Appui long sur l’icône CourseOK → Infos sur l’appli (ou Réglages → Applis → Gérer les applis → CourseOK).
  4. En haut à droite : ⋮ → Autoriser les paramètres restreints → confirme (empreinte / code PIN).
  5. Retourne dans Accessibilité et active CourseOK.

Autres Android (Pixel, etc.)

  1. Accessibilité → Applications téléchargées → touche CourseOK → message « Restricted setting ».
  2. Applications → CourseOK → ⋮ → Autoriser les paramètres restreints.
  3. Réactive CourseOK dans Accessibilité.

Si le ⋮ n’apparaît toujours pas

  • Refais l’étape Accessibilité (déclencher le message), puis rouvre Infos CourseOK tout de suite.
  • Ferme CourseOK des apps récentes, puis appui long → Infos.
  • Désinstalle CourseOK, réinstalle l’APK depuis Fichiers / Chrome, puis refais les étapes avant d’ouvrir l’app.
