01

Score avant d’accepter

Lecture d’écran Uber / Bolt / Heetch / Allocab → note /10, €/h, km et prix sur le bandeau.

02

Alerte « Sur notre chemin »

Si la destination est proche de ton adresse (rayon 2–20 km), un smiley s’affiche sur le verdict.

03

DashcamVTC (Play)

Pour sauvegarder tes trajets (avant / arrière + son), ouvre notre app dédiée DashcamVTC sur Google Play — depuis l’onglet Forfaits.

Retrouve les offres détectées, scores et trajets pour suivre ta journée.

Stats & packs

1000 analyses offertes. Ensuite packs SumUp ou code promo — tu paies les analyses, pas un forfait flou.
